Juego de dados para dos jugadores desarrollado en C++, aplicando programación modular, funciones, vectores, matrices y generación de números aleatorios.

# 🎲 Juego de Dados en C++

## Descripción del proyecto

Juego de dados para dos jugadores desarrollado en C++ como parte de mi formación en programación.

El proyecto consiste en una aplicación de consola que permite disputar partidas de tres rondas, generar lanzamientos aleatorios, calcular puntajes y consultar estadísticas.

## 🎮 Reglas del juego

- Participan dos jugadores.
- Cada partida consta de tres rondas.
- Cada jugador lanza cinco dados de seis caras por ronda.
- El jugador que comienza cada ronda se alterna.
- Los puntajes se acumulan durante toda la partida.
- Gana el jugador que obtiene el mayor puntaje total.
- En caso de igualdad, se declara un empate.

## ⚙️ Funcionalidades

- Menú principal interactivo.
- Registro y validación de nombres.
- Validación de opciones del menú.
- Generación aleatoria de dados.
- Representación gráfica de dados mediante caracteres ASCII.
- Alternancia de jugadores.
- Visualización de resultados parciales y finales.
- Registro del puntaje máximo y del jugador que lo consiguió durante la sesión.

## 📂 Estructura del proyecto

| Archivo | Responsabilidad |
|---|---|
| main.cpp | Punto de entrada del programa. |
| menu.cpp / menu.h | Gestión del menú principal. |
| jugabilidad.cpp / jugabilidad.h | Lógica y desarrollo de las partidas. |
| estadisticas.cpp / estadisticas.h | Visualización de estadísticas. |
| consigna.cpp | Consigna original del ejercicio. |
| clase02-6.cbp | Archivo del proyecto de Code::Blocks. |

## 🚀 Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir el archivo `clase02-6.cbp` con Code::Blocks.
3. Compilar y ejecutar el proyecto utilizando la opción Build and Run (F9).
